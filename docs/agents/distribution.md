# Distributing agent-made music

Flux marks agent output as AI-generated by default. This page explains what Flux writes and what the main platforms and rules expect as of October 2026. It is guidance, not legal advice; get counsel before commercial release.

## What Flux writes

Every agent render (long-form runs and `flux-ai generate` outputs) carries:

- **Embedded tags** in the audio file: `AI_GENERATED=1` and a human-readable disclosure string (FLAC Vorbis comments; RIFF INFO/iXML for WAV).
- **`provenance.json`** next to the file: the full plan, seeds, every backend with model id, version and weights licence, prompts, timestamps, the Flux version, and a human-decision log (which edits a person approved, from the undo history).
- **Chapters and cue sheet** for long-form output.

Watermarking is not on by default: no open audio watermark has been evaluated yet. The pipeline has a hook for one.

## Rules that apply

| Source | What it means for you |
|---|---|
| EU AI Act, Article 50 (applies from 2 August 2026) | Providers must mark AI-generated audio in a machine-readable, detectable way. The Code of Practice asks for at least two marking layers where needed, such as metadata plus a watermark. Whether a Flux user is a "provider" is a question for counsel. |
| Spotify | Backs DDEX AI-disclosure metadata (vocals, instrumentation, post-production) and removes spam: mass uploads, duplicates, artificially short tracks. Master to −14 LUFS integrated, true peak below −1 dBTP. |
| YouTube | The July 2025 "inauthentic content" policy demonetises mass-produced, repetitive uploads. Long AI mixes need visible human curation and variety. |
| Deezer | Detects and tags AI tracks automatically; most streams on fully AI tracks were found fraudulent and demonetised. |
| DistroKid | Asks uploaders to self-disclose AI use (since 2026). |
| US Copyright Office | Prompts alone don't make you an author. Human selection, arrangement and editing can be protected, so keep the provenance log. |

## Practical checklist

1. Keep the provenance file with the master; use it to fill distributor AI-disclosure fields.
2. Review and edit the plan and the result yourself; that review is both the quality gate and your evidence of human authorship.
3. Don't upload many near-identical long mixes; platforms treat that as spam.
4. Check each model's weights licence before commercial use ([backends.md](backends.md)).

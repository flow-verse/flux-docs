# Roadmap
1. **Foundation** — installer + PipeWire low-latency + stock host
2. **Suite** — Surge XT, Six Sines, DecentSampler, Signalsmith Stretch, NAM
3. **Modular layer** — Plugdata (+Cyclone), Cardinal, generative MIDI
4. **AI bridges** — Demucs, Basic Pitch, madmom, RAVE
5. **Hardware** — DrivenByMoss, MIDI 2.0 / MIDI-CI
6. **Stage** — Link, OSC, DMX, spatial audio, failover rig
7. **Edge** — crowd sensing with aggregate-only metadata
8. **Agents and generation** — headless engine with a JSON-RPC control API, MCP adapter, local generation backends (ACE-Step 1.5, Magenta RT 2), long-form orchestrator, provenance and AI disclosure (see `docs/agents/`)
